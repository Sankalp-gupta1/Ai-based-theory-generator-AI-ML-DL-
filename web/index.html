Local retrieval + theory drafting

Turn source notes into a structured theory draft.

The original project uses embeddings and GPT-2. This hosted no-key mode focuses on the same pipeline idea without pretending to run the heavyweight model: retrieve the most relevant source sentences for a topic and assemble a transparent theory-style draft.
